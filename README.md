# SpendWise - Mục tiêu tiết kiệm

## Tên đề tài
SpendWise - Quản lý ngân sách và thói quen chi tiêu.

## Trang thực hiện
Mục tiêu tiết kiệm (Saving Goals).

## Mục đích
Giúp người dùng tạo và theo dõi các mục tiêu tiết kiệm cá nhân.

## Chức năng chính
- Thêm, sửa, xóa mục tiêu.
- Góp thêm tiền vào mục tiêu.
- Tìm kiếm và lọc theo trạng thái.
- Tự tính tiến độ và số tiền cần góp mỗi tháng.
- Goal Coach đưa ra gợi ý tiết kiệm đơn giản.
- Kiểm tra dữ liệu form.
- Lưu dữ liệu bằng LocalStorage.
- Responsive trên điện thoại.

## Công nghệ
HTML, CSS, JavaScript, LocalStorage.
