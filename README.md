# SpendWise - Trang Mục tiêu tiết kiệm

## Tên đề tài
SpendWise - Quản lý ngân sách và thói quen chi tiêu.

## Tên trang đã thực hiện
Mục tiêu tiết kiệm - Saving Goals.

## Mục đích của trang
Trang giúp người dùng tạo và theo dõi các mục tiêu tiết kiệm cá nhân như quỹ khẩn cấp, mua laptop hoặc du lịch.

## Các chức năng chính
- Hiển thị tổng số mục tiêu, số tiền đã tích lũy, tiến độ chung và số tiền nên góp trong tháng.
- Thêm mục tiêu mới.
- Sửa mục tiêu.
- Xóa mục tiêu.
- Góp thêm tiền vào mục tiêu.
- Tìm kiếm mục tiêu theo tên.
- Lọc theo trạng thái.
- Tự tính phần trăm tiến độ và trạng thái mục tiêu.
- Goal Coach mô phỏng bằng JavaScript cơ bản để gợi ý số tiền nên tiết kiệm mỗi tháng.
- Lưu dữ liệu bằng LocalStorage.
- Responsive cơ bản cho điện thoại.

## Công nghệ sử dụng
- HTML5 semantic.
- CSS3, Flexbox, Grid, Media Query.
- JavaScript cơ bản: let/const, function, array, object, if/else, loop, DOM, event, validation, render dữ liệu.
- LocalStorage để lưu dữ liệu trên trình duyệt.
